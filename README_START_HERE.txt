AI OPERATIONS WORKBENCH - QUICK START

1. FIRST TIME ONLY
   Double-click: setup_workbench.bat

2. START THE COMPLETE WORKBENCH
   Double-click: start_workbench.bat

3. The launcher starts:
   - Compressor Health API       : port 8001
   - Feed Optimizer API          : port 8002
   - Visual Operator Rounds API  : port 8003
   - Technology Intelligence API : port 8004
   - Unified Streamlit website   : port 8501

4. Open the Workbench at:
   http://localhost:8501

5. Keep the command windows open while using the Workbench.

UNIFIED WEBSITE
- Home: portfolio overview + live local service status
- Module 1: Compressor Health Monitoring
- Module 2: Gas Feed Allocation Optimizer
- Module 3: Visual Operator Rounds
- Module 4: Oil & Gas Technology Intelligence
- Architecture & About: end-to-end design + productionization roadmap

MODULE 4 / LLM ACCESS
- Your private .env/API key is intentionally not included in this distributable.
- Module 4 can run with its clearly labelled rule-based fallback.
- To enable live LLM analysis, create "Market Intelligence\.env" from
  ".env.example" and add your own API key/model configuration.
