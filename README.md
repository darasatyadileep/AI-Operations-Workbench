# AI Operations Workbench

Portfolio project demonstrating an end-to-end industrial AI application across predictive analytics, optimization, computer vision, and GenAI/search-enabled intelligence workflows.

## Architecture

React frontend → FastAPI services → Python engines/models → decision outputs.

The project is being evolved from a local development setup into an Azure-hosted public application.

## Modules

### 1. Compressor Health
Isolation Forest + StandardScaler with FastAPI inference.

### 2. Feed Allocation Optimizer
SciPy linear programming with editable operational and economic assumptions.

### 3. Visual Inspection
OpenCV + EasyOCR for equipment nameplate reading.

### 4. Technology Intelligence
Search/RAG-oriented intelligence workflow with evidence-backed synthesis and persistent history.

## Important

Operational data and economics in this portfolio are synthetic demonstrations for learning and architecture purposes.
