AI Operations Workbench — Professional Web v2

What changed in v2
- Feed Optimizer is now a real scenario workspace rather than a single Run button.
- Editable feed availability and composition.
- Editable plant and fractionator capacities/recoveries.
- Editable product prices.
- Quick reset to the sample scenario.
- Excel workbook upload option.
- Results dashboard with baseline vs optimized value, uplift, feed utilization, plant utilization, and route-level allocation.
- Backend optimizer API now accepts scenario inputs dynamically.

Launch
1. Install Node.js LTS once.
2. Run setup_workbench.bat once if Python packages are not already installed.
3. Double-click start_professional_web.bat.
4. Browser opens at http://127.0.0.1:5173

Important
- Values and economics are synthetic demonstrations, not actual operating savings.
- Technology Intelligence live web research requires an OpenAI API key with available API credits.
- This package is still a local-development version; public Azure deployment comes after local verification.
